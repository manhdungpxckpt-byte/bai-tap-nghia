# 📚 Bài tập của Nghĩa

Chào mừng đến với repo lưu trữ bài tập của Nghĩa! 🎓

## 📖 Giới thiệu

Repo này dùng để lưu trữ và quản lý các bài tập của Nghĩa trong quá trình học tập.

## 📁 Cấu trúc thư mục

Mỗi bài tập sẽ được đặt trong một thư mục riêng, ví dụ:

```text
bai-tap-nghia/
├── bai-tap-01/
├── bai-tap-02/
├── bai-tap-03/
└── ...
```

## 📂 Nội dung hiện có

- [`matlab/`](matlab/) — **Giáo trình MATLAB/Simulink tiếng Việt**: mô phỏng hệ thống truyền lực đến các bánh xe chủ động (lý thuyết + code chạy được + bài tập)

## 🚀 Cách sử dụng

1. Clone repo về máy: `git clone https://github.com/manhdungpxckpt-byte/bai-tap-nghia.git`
2. Tạo thư mục cho bài tập mới
3. Commit và push bài làm lên GitHub
